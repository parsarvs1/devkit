# DevKit Examples

Practical examples for every DevKit tool. Each example shows a real use case with exact input and expected output.

## How to Use These Examples

- Examples are organized by tool and use case.
- Each example includes the problem, sample input, expected output, and explanation.
- Links connect back to the tool page and its full documentation.
- Examples are verified against the actual implementation.
